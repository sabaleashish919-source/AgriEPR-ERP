## 📌 Overview

**AgriEPR ERP** is a modern **Enterprise Resource Planning (ERP)** system built with **Flask** for agricultural businesses. It streamlines inventory, supplier, customer, purchase, sales, and billing operations through a clean, user-friendly web interface.

The system is designed to help agro agencies efficiently manage daily business activities while reducing manual work and improving operational accuracy.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/sabaleashish919-source/AgriEPR-ERP.git
```

### Navigate to Project

```bash
cd AgriEPR-ERP
```

### Create Virtual Environment

```bash
python -m venv env
```

### Activate Virtual Environment

**Windows**

```bash
env\Scripts\activate
```

**Linux / macOS**

```bash
source env/bin/activate
```

### Install Project Requirements

After activating the virtual environment, install all required Python dependencies using the `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

### Open in Browser

After starting the Flask server, open:

```text
http://127.0.0.1:5000
```
